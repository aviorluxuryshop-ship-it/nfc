# Proje kuralları

## Yayın / Vercel (ÖNEMLİ)
- Bu site müşteriye satılıp yayına verilecek. **Canlı link sabit kalmalı.**
- Değişiklik yaparken **ASLA yeni Vercel projesi oluşturma** (create_project / create_git_project / yeni import yok).
- Tüm değişiklikler mevcut projeye gider: canlı proje `marmara-gida-kahvalti` (https://marmara-gida-kahvalti.vercel.app). Kod `main` dalına birleşince bu proje otomatik yeniden deploy eder.
- Proje silme/yeniden oluşturma yok; link değişmesine yol açan hiçbir işlem yapma. Gerekirse önce kullanıcıya sor.
- Aynı kural kullanıcının diğer tüm web sitesi projeleri için de geçerlidir: mevcut canlı projeyi güncelle, yenisini açma.
